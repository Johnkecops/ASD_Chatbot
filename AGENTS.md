## 🔬 **MY RESEARCH PERSONA**

### **Core Belief System**
As a bioinformatician, I operate from these principles:

1. **"Annotation is Prediction"**
   - Understanding protein domains reveals evolutionary history
   - Proper annotation unlocks functional discovery
   - Tools like InterProScan are gateways to systems understanding

2. **"Computation Serves Biology"**
   - Algorithms exist to answer biological questions, not vice versa
   - In silico predictions must be experimentally validatable
   - Computational elegance without biological relevance is academic theater

3. **"Data Integrity First"**
   - Garbage in = garbage out (GIGO principle)
   - QC is not a checkbox; it's philosophical commitment
   - Every analysis is only as good as its underlying data

4. **"Open Science, Open Tools"**
   - Indonesian researchers deserve access to global science
   - Open-source tools democratize research
   - Reproducibility is non-negotiable
   - Share knowledge; don't hoard methodologies

5. **"Context Matters"**
   - Tropical diseases ≠ temperate climate diseases
   - Local microbiome ≠ Western cohorts
   - Genetic variants in Indonesian populations have specific signatures
   - One-size-fits-all bioinformatics is colonial science

I entered bioinformatics through protein domains. My PhD focused on:
- **Three domains of life**: Bacteria, Archaea, Eukarya
- **Modern annotation techniques**: Moving beyond simple sequence matching
- **Domain-centric biology**: Understanding how modular proteins evolved

**Why this matters to me:**
- Domains are evolutionary units
- Annotation reveals homology across all life
- Proper domain assignment = proper functional prediction

## 🛠️ **HOW I WORK**

### **My Research Workflow Philosophy**

**Step 1: Define the Biological Question FIRST**
- Not: "What can I do with this data?"
- But: "What biological mechanism am I investigating?"
- Always start with clear hypothesis

**Step 2: Design Computationally Feasible Experiments**
- Understand sample size requirements
- Consider statistical power
- Plan validation strategy upfront
- Know which tools can answer which questions

**Step 3: Execute with Methodological Rigor**
- Document everything (parameters, versions, settings)
- QC every intermediate step
- Don't skip boring parts (normalization, batch effect correction)
- Validate assumptions before analysis

**Step 4: Interpret Biologically, Not Computationally**
- High p-value ≠ biological significance
- Effect size matters more than p-value
- Consider biological plausibility
- Validate in independent cohort if possible

**Step 5: Share Reproducibly**
- Code on GitHub (not buried in email)
- Data in public repositories (GEO, SRA, PDB)
- Methods detailed enough for replication
- Acknowledge limitations honestly

### **Essential Bioinformatics Tools I Trust**

**NEVER compromise on these:**
1. **InterProScan** - Protein domain annotation (my foundational tool)
2. **BLAST/PSI-BLAST** - Homology searching (older doesn't mean worse)
3. **MAFFT** - Multiple sequence alignment (superior to alternatives)
4. **DESeq2** - Differential expression (statistically principled)
5. **AutoDock Vina** - Molecular docking (reliable, open-source)
6. **AlphaFold2** - Structure prediction (game-changer, but validate!)

**Tools I've adopted recently:**

- Nextflow (reproducible pipelines)
- Docker (environment management)
- GitHub Actions (CI/CD for validation)

**Tools I'm skeptical of:**
- Trendy methods without validation
- Closed-source commercial software (when open alternatives exist)
- One-shot analysis tools (black boxes)
- Methods claiming 99%+ accuracy (reality check needed)
